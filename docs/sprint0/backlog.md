# Sprint 0

## Objectif du sprint

L’objectif de ce sprint est d’obtenir une première version utilisable de l’application permettant à un utilisateur de se connecter, de consulter son agenda et de gérer simplement ses événements.

## Backlog du sprint courant

À l’issue de cette première itération, l’utilisateur doit pouvoir :

- accéder à l’application ;
- créer un compte utilisateur ;
- se connecter avec un compte existant ;
- arriver sur une vue calendrier affichée à la semaine après connexion ;
- consulter un agenda ;
- créer un nouvel événement depuis l’interface ;
- modifier un événement existant ;
- supprimer un événement existant ;
- retrouver ses comptes, agendas et événements après une fermeture puis une nouvelle ouverture de l’application.
